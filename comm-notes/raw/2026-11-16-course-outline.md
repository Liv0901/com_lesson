# 通訊原理 課程大綱與重點筆記

> 範例原始資料：老師整理的課程大綱。之後可替換或新增實際上課筆記、課本摘錄。

## 第 1 單元 訊號與頻譜
- 週期 T、頻率 f = 1/T、角頻率 ω = 2πf
- 時域看波形隨時間的變化；頻域看由哪些頻率組成（傅立葉）
- 頻寬 B = fmax − fmin；電話語音約 300 Hz 到 3400 Hz，頻寬 3.1 kHz

## 第 2 單元 AM 調變
- 調變目的：縮短天線長度、讓不同電臺分到不同頻段
- s(t) = Ac[1 + μ cos(2πfm t)] cos(2πfc t)
- 調變指數 μ = Am / Ac，需 ≤ 1，μ > 1 為過度調變，包絡檢波失真
- 頻寬 B = 2W；功率效率 η = μ² / (2 + μ²)，μ = 1 時約 33%
- AM 廣播音訊上限 5 kHz，每臺頻寬 10 kHz

## 第 3 單元 FM 調變
- 振幅固定，訊息改變載波頻率
- 最大頻率偏移 Δf；調變指數 β = Δf / fm，可大於 1
- 卡森法則：B ≈ 2(Δf + fm) = 2(β + 1)fm，約含 98% 功率
- FM 廣播：Δf = 75 kHz，音訊上限 15 kHz，β = 5，頻寬約 180 kHz
- 優點：抗雜訊（雜訊多在振幅，接收機可限幅）；代價：頻寬較寬
- β 很小時為窄頻 FM，頻寬約 2fm

## 第 4 單元 取樣定理（尚未上課）
- 取樣率需大於訊號最高頻率的 2 倍（奈奎斯特率）
- 取樣不足會產生混疊（aliasing）
- 待補：課本例題、抗混疊濾波器
